# 구글 시트 자동 받기 설치 (PC에서 하면 편해요)

1. 구글 시트를 새로 만들어요. 이름은 자유예요. (학교 구글 계정이 있으면 그 계정으로)
2. 메뉴 **확장 프로그램 → Apps Script**를 열어요.
3. 기존 코드를 모두 지우고 `Code.gs`의 내용을 붙여 넣어요.
4. 맨 위 두 값을 바꿔요.
   - `CLASS_CODE`: 학생 링크에 들어가는 반 코드 (예: 우리반-7391)
   - `TEACHER_KEY`: 선생님만 아는 긴 비밀 키 (남에게 알려 주지 마세요)
5. 저장(💾) 후 **배포 → 새 배포 → 유형: 웹 앱**을 골라요.
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
6. 처음 배포할 때 권한 승인 화면이 나와요. 본인 계정으로 허용해 주세요.
7. 배포가 끝나면 **웹 앱 주소**(`https://script.google.com/macros/s/.../exec`)가 나와요. 복사해 두세요.
8. 교사용 화면(`t-jidang.html`)의 **구글 시트 연결**에 주소, 비밀 키, 반 코드를 넣고 **저장**해요.
9. **학생 링크 만들기**를 눌러 나온 링크를 학생들에게 나눠 줘요. 학생이 처음 한 번 열면 연결돼요.

## 확인
- 학생 앱 목표 탭에 "지금 보내기"가 보이면 연결된 거예요.
- 학생이 보내면 시트의 `현황` 탭에 한 줄이 생기거나 갱신돼요.
- 교사용 화면에서 **시트에서 불러오기**를 누르면 현황이 보여요.

## 코드를 고쳤을 때
Apps Script에서 **배포 → 배포 관리 → 수정(연필) → 새 버전**으로 다시 배포해요. 주소는 그대로예요.

## 개인정보
- 보내는 정보는 별명, 기록한 날 수, 연속 일수, 칭호, 퀘스트 수, 쿠폰 상태뿐이에요. 쓴 글은 가지 않아요.
- 데이터는 선생님 구글 계정의 시트에만 쌓이고, 선생님이 직접 지울 수 있어요.
- 사용 전에 학교 정보보호 담당 선생님과 보호자 동의 절차를 확인해 주세요.
